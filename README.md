# Detector AI Audio Test

Prototype indépendant destiné à vérifier l'acquisition audio Web/PWA du RØDE AI-Micro sur iPhone.

## Test
1. Héberger ce dossier en HTTPS (par exemple GitHub Pages).
2. Ouvrir la page sur l'iPhone.
3. Brancher le RØDE AI-Micro (DEUS II + micro cravate).
4. Appuyer sur « Autoriser le micro ».
5. Observer les entrées audio, le nombre de canaux et le niveau.
6. Essayer chaque entrée proposée et produire quelques sons DEUS II.
7. Faire un enregistrement de 10 secondes et le réécouter.

Ce prototype ne modifie pas Detector AI et n'envoie pas l'audio vers un serveur.
